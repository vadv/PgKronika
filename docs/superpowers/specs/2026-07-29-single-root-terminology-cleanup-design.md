# Очистка следов прежнего глобального пространства

Дата: 2026-07-29

## Цель

Текущее дерево PgKronika не содержит прежних имён глобального числового
пространства. Запрет распространяется на production-код, тесты, комментарии,
документацию, планы, qualification-артефакты, скрипты и CI.

История Git не переписывается. Старые версии остаются доступны только через
историю коммитов и не присутствуют в текущем дереве.

## Запрещённые термины

Проверка строит две строки из фрагментов:

- `"source_" + "id"`;
- `"KRONIKA_SOURCE_" + "ID"`.

Ни одна из полученных строк не должна встречаться в файлах текущего дерева.
Составление из фрагментов позволяет самому guard не нарушать проверяемый
инвариант.

## Изменения

1. Удалить спецификацию и план завершённой миграции. Они не являются текущим
   контрактом, а история Git сохраняет их при необходимости.
2. Из действующих документов удалить устаревшую ось глобального пространства.
   Требования переписать в терминах одного корня данных, точного дескриптора
   файла, `node_self_id`, typed entity identity и contract revisions.
3. Исторические документы в текущем дереве либо привести к актуальным
   single-root формулировкам, либо удалить, если после очистки они не содержат
   действующего контракта.
4. Qualification JSON сохранить только с актуальными size, RSS, I/O,
   determinism, contract-inventory и временными измерениями. Удалить прежнее
   поле и проверки его ненулевого значения. Валидатор проверяет актуальные
   identity-инварианты формата.
5. Переименовать нейтральные локальные идентификаторы:
   - снимок исходного файла: `input_file_identity`;
   - байты typed entity identity: `entity_identity_bytes`;
   - dictionary ID строки mount source: `source_str_id`.
6. Удалить отрицательные тесты, которые сохраняют имя удалённого поля.
   Контракт отсутствия лишних полей проверять точным набором свойств или
   закрытой схемой.
7. Добавить CI guard, который собирает запрещённые строки из фрагментов и
   проверяет tracked tree. Guard запускается до дорогих Rust-проверок.

## Совместимость

Compatibility field, sentinel, alias, migration reader и старый query
parameter не добавляются. Wire format и API остаются single-root.

Переименование локальных переменных не меняет файловую проверку подмены,
хеширование typed identities, сериализацию или resource bounds.

## Проверка

Готовность подтверждают:

1. пустой поиск обеих собранных строк во всём текущем дереве, кроме `.git`;
2. успешные qualification validators;
3. `cargo fmt --all --check`;
4. strict workspace clippy;
5. workspace tests;
6. `cargo run -p xtask -- check-deps`.

Любое новое совпадение является ошибкой CI.
